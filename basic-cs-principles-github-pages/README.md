# Basic CS Principles

A small GitHub Pages site for basic computer science concepts explained in plain language.

## Topics
- Recursion and base cases
- Hash maps
- BFS vs. DFS
- Convolutional neural networks
- NP-hard vs. NP-complete
- I²C with Arduino

The repository also includes `recursion-demo.ps1`, the saved PowerShell WinForms recursion demo.

## GitHub Pages

1. Create a new GitHub repository.
2. Upload all files in this folder to the repository root.
3. Commit them to `main`.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose the `main` branch and `/ (root)`.
7. Save.

GitHub will provide the public Pages URL after deployment.
