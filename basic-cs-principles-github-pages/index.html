01

Recursion + Base Case

function → itself

Recursion is when a function calls itself with a smaller version of the same problem. A base case is the stopping condition.

recursion = function calls itself // base case = where it stops

Example

factorial(5)
= 5 * factorial(4)
= 5 * 4 * factorial(3)
= 5 * 4 * 3 * factorial(2)
= 5 * 4 * 3 * 2 * factorial(1)

factorial(1) = BASE CASE

What happens

  1. The function receives a problem.
  2. It calls itself with a smaller problem.
  3. It eventually reaches the base case.
  4. The answers return back up through the earlier calls.

02

Hash Maps

key → value

A hash map stores a value under a key. A hash function turns the key into a location so the computer can usually jump close to the answer instead of searching every item one by one. 

"Ti" → hash function → location 27 → phone number

Remember it like lockers: instead of checking every locker, the key tells you which locker to go to.

03

BFS vs. DFS

wide vs. deep

Breadth-First Search

Searches level by level. It checks nearby choices before going deeper.

A → B → C → D → E → F

Think: search wide first.

Depth-First Search

Follows one path as far as possible, then backs up and tries another.

A → B → D → E → C → F

Think: search deep first.

Maze version: BFS checks every nearby hallway. DFS picks one hallway and keeps going.

04

Convolutional Neural Networks

pixels → patterns

A CNN is a neural network that is especially useful for images. Small learned filters slide across an image looking for patterns.

pixels→edges→shapes→objects

It is efficient because the same learned filter can be reused across the whole image instead of learning a completely separate rule for every pixel location.

A tensor is the data structure holding the image numbers. The important CNN idea is the reusable filter sliding across those numbers.

05

NP-Hard vs. NP-Complete

difficulty classes

NP: if someone gives you a proposed answer, you can check it efficiently.

NP-hard: at least as hard as the hardest problems in NP.

NP-complete: both NP and NP-hard.

NP-complete = NP + NP-hard

Sudoku idea: finding a solution can be hard, but checking a completed board is much easier.

06

I²C + Arduino

device communication

I²C is a communication system that lets a controller such as an Arduino talk to sensors, displays, accelerometers, clocks, and other devices.

SDA

Serial Data

The actual information being sent.

SCL

Serial Clock

The timing that keeps communication synchronized.

Arduino
  ├── 0x3C → OLED display
  ├── 0x48 → temperature sensor
  └── 0x68 → accelerometer

SDA = what is being said // SCL = when it is being said // address = which device.
